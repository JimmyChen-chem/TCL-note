## 0.2 运行 TCL 解释器

运行tcl的方法很多，例如你可以在 mac 的 zsh 中进行如下命令：
1. 在终端里输入 `tclsh`（这是 Tcl 的交互式解释器）并回车。
2. 你的终端提示符会变成一个 `%`，这说明你已经进入了 Tcl 的解释器界面。
3. 如果要退出，则直接 `exit` 即可。也可以是 `brew install tcsh`。

在 vscode 里，你不仅要安装一个 **Code Runner** 的 extension，而且还要去 **command palette** 里进行设置（*因为 code runner 识别不了 tcl 语言*）。
下面我们进行 code runner 的配置：
1. 可以 cmd+shift+P 直接打开，也可以是 view - command palette
2. 在弹出的搜索框里输入：
`Open Settings (JSON)`
3. 点击 Preferences: Open User Settings (JSON)
4. 添加 Tcl 运行规则：你会看到一个包含各种设置代码的文件（最外层是一对大括号 {}）。
请在这个文件里，找一个合适的地方（比如最后一行代码的上面），复制并粘贴下面这段代码：
```bash

    "tcl": "tclsh"
},
"code-runner.executorMapByFileExtension": {
    ".tcl": "tclsh"
}
```

# *Chapter 1*: TCL 语法

## 1.1 脚本 & 命令 & 单词符号  

首先我们来看看 tcl 解释器的基本语法和一些常用的命令。  

tcl 是一种**脚本语言**，它的语法非常简单，主要由**命令和参数**组成。
**每个命令都以一个单词开头，后面跟着一些参数，这些参数可以是字符串、数字或者其他命令的结果。**  

一个 tcl 脚本可以包含一个 & 多个命令，具体来说有几个要求：
- 命令之间 必须用 *换行符* 或者 *分号 `;`* 分隔开来
- 每个命令都由一个单词符号开头，后面跟着一些参数。
- 单词之间（注意这里是”单词之间“，而上文的要求的是“命令之间”）必须用 *空格* 或者 *TAB 键* 分隔开来，不能使用其他的分隔符，例如逗号或者冒号。
- tcl 的**每一个命令**会**包含一个或几个单词**。
- 一般来说，第一个单词代表命令名，另外的单词则代表的是前面函数(命令)的参数。

例如下面的两个例子都是被允许的：  

#### *example_1*. 使用换行符分隔命令,单词之间用空格：
```tcl
set a 1
set b 2
```
#### *example_2*. 使用分号分隔命令，单词之间用空格：
```tcl
set a 1; set b 2
```

下面我们再举一个简单的例子,来体会微妙的区别。  

#### *<a id="ex_1.1_3">example_3</a>*. 需要注意的是，以下表达都是显示变量 `sel` 的值:

```tcl
set sel
puts $sel
```

关于这两个的具体区别，下面具体论述：  

```tcl
set sel 
```

- set 命令： set 是 Tcl 中用于处理变量的头号命令。
- 它有两种用法：
  - **赋值**（两个参数）： set sel 100 // 把 100 存进名为 sel 的盒子里
  - **读取**（一个参数）： 当前就是这种情况。当你只给 set 一个参数时，它的作用是返回这个变量当前的值。

因此，若先设：  

```tcl
set sel "Hello"
```

再输入：  

```tcl
set sel
```

则程序内部会得到 `Hello` 的字符串，但不会打印到屏幕上（除非是交互式终端才会默认把你“拿出来”的值显示在屏幕上。）
**在普通的脚本文件中，单纯写一行 `set sel` 几乎没有意义**，因为它只是把值“***拿出来***”了一下，并没有打印到屏幕上，也没有传递给其他命令。  

```tcl
puts $sel
```

- `puts` 命令：`puts` 的全称是 `put string` （输出字符串），可以把你给它的内容打印到屏幕（终端）上，方便阅读。
- 而这里 `puts（命令） $sel(参数)` ，`$` 在 tcl 中意思是“替换为该变量的值”（*下面我们将详细讲解*）。
简单来说，tcl 先读到 `$sel` 这个字符串，由于有 \$ , tcl 会去内存里查找 `sel` 这个变量具体是什么（sel 这个盒子里装了什么）。

由上可知：如果不对 sel 这个参数进行赋值，则也无输出，因此要写成：  

```tcl
set sel "Hello"
puts $sel
```

执行上述命令，如此以来便可以看到打印了 `Hello` 的字样。

**总结：在 tcl 中，变量的值可以通过 \$ 符号来引用。**

**TCL 解释器对一个命令的求值过程分为两部分：分析 & 执行。**
- **分析阶段：** TCL 解释器运用规则，会将输入的命令分解成***一个个独立的单词***，同时进行必要的**替换（substitution）**。
- **执行阶段：** TCL 解释器会把第一个单词当作命令名，并且查看和这个命令是否有定义。如果有定义，就激活这个命令对应的 C/C++ 过程，并把所有单词作为参数传递给该命令过程，让命令过程进行处理。

前面我们已经提到过，在 tclsh 解释器中，‘`%`’ 为 TCL 的命令提示符（下面的命令我们会省略掉 `%`，但请别忘记！），输入命令回车后，TCL 会在接着的一行输出命令执行结果

## 1.2 置换功能的使用
### 1.2.1 引入的例子
十分重要的一点‼️：**TCL 解释器在分析命令时，把所有的命令参数都当作字符串来看待（万物皆单词）。**
下面我们来看几个例子，体会一下这是何意味。

#### *ex_1*：  

```tcl
set x 10 # 定义变量x,并把x的值赋为10
10 # 交互式终端的输出结果
set y x+100 # y的值是x+100,x被当作是字符串x+100的一部分
x+100 # 交互式终端的输出结果
```

这一点和现代的语言十分不一样，若用现代解释器，这个输出应该为110，因此需要适应 tcl 语言的独到之处。
- *如果使用前面 [1.1节](#11-脚本--命令--单词符号) 的 [example_3](#ex_1.1_3) 的 '\$' 会如何？*  

#### <a id="ex_1.2.1_2">*ex_2*</a>:  

```tcl
set x 10
set y $x+100
10+100 //这里仅仅是'$x'这一部分被替换为上面赋值的‘10’，10+100 被 tcl 当作一个字符串而非表达式
```

如果我们想使用 x 定义的值`10`，就必须告诉 tcl 解释器这里期望的是***变量 x 的值***，**而非字符`x`**。  

如何告诉 tcl 这个需求？就要用到 tcl 语言中提供的**置换功能**。

**TCL 提供三种形式的置换：**
- **变量置换**
- **命令置换**
- **反斜杠置换**
注：（1）每种置换都会导致一个或多个单词本身被其他的值所代替；（2）置换可以发生在包括命令名在内的每一个单词中；（3）置换可以嵌套。

### 1.2.2 变量置换（variable subtitution）

- **变量置换由一个 \$ 符号标记；**
- **变量置换会导致变量的值插入一个单词中。**
  
例如上述的 [ex_2](#ex_1.2.1_2) 中的 `set y $x+100`,因为 tcl 把 10+100 **看作一个字符串而不是表达式**。
y要想得到值110，还*必须用命令置换*，才能让 tcl 把10+100看作一个表达式从而求值。

### 1.2.3 命令置换（command substitution）
- **命令置换是由 `[ ]` 括起来的 TCL 命令及其参数**
- **命令置换会导致某一个命令的所有或部分单词被另一个命令的结果所代替。**

下面举一个例子：

```tcl
set x 10
set y [expr $x+100]
110
```

这里y值成功得到了我们期望的110。不难理解，根据上面的第二点来看，`[ ]` 将其括号内的首个单词的内容重新当作一个新的命令，此时先处理括号内的内容：`expr` 变成了括号内的命令名，从而激活与 `expr` 对应的 C/C++过程，计算 `$x` 变量置换后的 `10+100` 的值。  

几点提醒：
- **如果在上例中我们去掉 `[ ]`，那么 TCL 会报错**。因为在正常情况下，**TCL 解释器只把命令行中的第一个单词作为看作命令**，其他的单词都作为**普通字符串**处理，**看作是命令的参数**。  
- `[ ]` 中必须是一个合法的 TCL 脚本，**长度不限**。
- `[ ]` 中**脚本的值为最后一个命令的返回值**  

下面我们举个例子来体现上面几点提醒的重要性：
```tcl
set y [expr $x+100; set b 300] # 优先处理 [ ] 的内容，而分号与换行符是分隔命令的，是允许的。故方括号内的最后一个命令是 set b 300，所以 y 的返回值为 300
```

总结：有了命令置换，实际上就表示**命令之间是可以嵌套的**，即**一个命令的结果可以作为别的命令的参数**。  

### 1.2.4 反斜杠置换 (backslash substitution)  

TCL 语言中的反斜杠置换类似于 C 语言中反斜杠的用法 (以及 Markdown 语言也是如此)，**主要用于在单词符号中插入诸如 `换行符`、`空格`、`[`、`$` 等被 TCL 解释器当作特殊符号对待的字符**。
